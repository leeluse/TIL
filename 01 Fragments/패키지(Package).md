### npm 이전에는 무엇이 문제였을까?
---
`npm`을 이해하려면 우선적으로 `패키지(Package)`에 대한 이해가 필요하다  

우리는 개발하면서 모든 기능을 직접 만들지 않고 타 개발자가 공개한 코드를 이용한다

```jsx
HTTP 요청     → axios
날짜 처리      → dayjs
React          → react
빌드 도구      → vite
코드 검사      → eslint
```

이러한 재사용 가능한 코드 묶음을 `패키지(package)`라고 생각하면 된다  

`npm`은 이런 패키지를 _‘어디서 가져오고, 어떤 버전을 사용하고, 어떤 프로젝트에서 사용하는지’_ 관리해 주는 툴이다
