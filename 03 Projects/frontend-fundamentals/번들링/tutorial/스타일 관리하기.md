### CSS를 모듈처럼 사용하기
---
기존에는 HTML 파일에서 `<link>` 태그로 CSS를 불러왔지만 **웹팩을 사용하면 JavaScript에서 CSS를 import할 수 있다** 
이렇게 하면 CSS도 모듈처럼 관리할 수 있고, 필요한 스타일만 번들에 포함시킬 수 있다

```tsx
// CSS를 import하면 웹팩이 알아서 처리해요
import "./style.css";
```

### 1. CSS 로더 설치하기
---
웹팩이 CSS를 처리할 수 있도록 필요한 로더들을 설치하자

```bash
npm install --save-dev style-loader css-loader
```

- `css-loader`: CSS 파일을 JavaScript에서 import할 수 있는 형태로 변환
- `style-loader`: 변환된 CSS를 브라우저 실행 시 `<style>` 태그로 만들어 동적으로 삽입

### 2. 웹팩에 CSS 로더 설정 추가하기
---
`webpack.config.js` 파일에 CSS를 처리하는 로더를 추가

```json
module.exports = {
  // ... 기존 설정 유지
  module: {
    rules: [
      // ... 기존 rules 유지
      {
        test: /\.css$/, // .css 파일을 처리해요
        use: [
          'style-loader', // CSS를 <style> 태그로 주입해요
          'css-loader' // CSS를 JavaScript 모듈로 변환해요
        ]
      }
    ]
  }
};
```

로더는 배열의 뒤에서부터 앞으로 순서대로 실행돼요. 즉, `css-loader`가 먼저 실행되고, 그 다음 `style-loader`가 실행되는 거예요.

### 3. 스타일 파일을 HTML에서 JavaScript 파일로 옮기기
---
먼저 `index.html` 에서 `style link 태그`를 제거한다

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Emoji of the Day</title>
  <link href="https://fonts.googleapis.com/css2?family=Inter:wght@500&display=swap" rel="stylesheet">
  <!-- HTML에 넣었던 style을 지워주세요 -->
  <!-- <link rel="stylesheet" href="./style.css"> -->
</head>
<!-- 동일 -->
</html>
```

`App.tsx` 에 `style.css` 파일을 import 한다

```tsx
import React from 'react';
import { emojis } from './emoji';
import { format } from 'date-fns';
import './style.css';

// 동일
```

### 4. 빌드하기
---
이제 코드를 빌드하자

```
npm run build
```

브라우저에서 `index.html`을 열어보면, HTML 안에 스타일이 직접 보이지 않더라도 페이지에는 CSS가 잘 적용된 걸 확인할 수 있다
