웹사이트를 만들다 보면 이미지, 아이콘, 폰트 같은 파일들을 자주 사용하게 된다

이런 파일은 JavaScript나 CSS처럼 코드로 변환하지 않고 `그대로` 브라우저에서 사용되는 파일이다
그래서 보통 `정적 자원`이라고 부른다

이번 단계에서는 프로젝트의 이미지와 폰트 같은 `정적 자원`을 웹팩으로 관리하는 방법을 배워 보자
웹팩의 `Asset Modules`([[Asset Modules]])를 사용하면 이런 파일들도 JavaScript 모듈처럼 import해서 사용할 수 있다



### 웹팩에 Asset Modules 설정 추가하기
---
`webpack.config.js` 파일을 수정하자

```js
module.exports = {
  // ... 기존 설정 유지
  module: {
    rules: [
      // ... 기존 rules 유지
      {
        test: /\.(png|svg|jpg|jpeg|gif)$/i, // 이미지 파일 확장자
        type: "asset" // Asset Modules 사용
      }
    ]
  }
};
```


### 이미지 파일 JS에서 import하기
---
`App.tsx`에서 logo 파일을 import하고 로고 이미지 태그 `src`에 넣으면 된다

```tsx
// logo.svg 를 import로 가져옴
import logo from "./assets/logo.svg";

// 가져온 logo 모듈을 src에 넣어줌
<img src={logo} alt="Logo" className="logo"></img>;
```

코드를 빌드하고 브라우저에서 로고 이미지가 잘 보이는지 확인하자

```
npm run build
```

 > 만약 아래와 같은 에러가 발생한다면, 이는 TypeScript가 이미지 파일을 모듈로 인식하지 못해서 발생하는 문제다
	`Cannot find module './assets/logo.svg' or its corresponding type declarations.`


`src/global.d.ts` 파일을 생성하고 아래 내용을 추가해 줘야 한다

```ts
declare module "*.png";
declare module "*.jpg";
declare module "*.svg";
```

이렇게 하면 `.png`, `.jpg`, `.svg` 같은 이미지 파일을 TypeScript에서 정상적으로 import할 수 있다




### CSS에서 이미지와 폰트 사용하기
---
폰트 파일도 같은 방식으로 사용할 수 있으니 `index.html`에서 폰트 파일을 지우자

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Emoji of the Day</title>
  <!-- HTML에 넣었던 폰트 파일 링크를 지워주세요 -->
  <!-- <link href="https://fonts.googleapis.com/css2?family=Inter:wght@500&display=swap" rel="stylesheet"> -->
</head>
<body>
  <div id="root"></div>
  <script src="./dist/bundle.js"></script>
</body>
</html>
```

`webpack.config.js`에 폰트 파일 처리를 추가하자

```js
module.exports = {
  module: {
    rules: [
      {
        test: /\.(woff|woff2|eot|ttf|otf)$/i, // 폰트 파일 확장자
        type: "asset/resource", // 폰트는 항상 별도 파일로 내보내요
        generator: {
          filename: "assets/[name][ext]" // 원하는 폴더와 이름 형태로 설정
        }
      }
    ]
  }
};
```

이제 css 파일에서 폰트 파일을 직접 접근할 수 있다

```css
/* style.css */
@font-face {
  font-family: "Inter";
  src: url("./assets/Inter-Regular.woff2") format("woff2");
}

body {
  font-family: "Inter", sans-serif;
}
```



#### 폰트를 별도의 파일로 내보내야 하는 이유?
---
폰트는 이미지보다 훨씬 용량이 크고, 자주 바뀌지 않는 정적 자원이다
그래서 다음과 같은 이유로 항상 `asset/resource`처럼 별도 파일로 내보내는 것이 좋다

- **성능**: JavaScript에 `inline`하면 번들 크기가 커져서 초기 로딩 속도가 느려져요.
- **렌더링 시점 제어**: 브라우저는 외부 폰트를 병렬로 다운로드하고 캐시할 수 있지만, 폰트를 JavaScript 코드 안에 base64로 포함하면, HTML이 파싱되고 JavaScript가 실행된 뒤에야 폰트를 사용할 수 있어요.
- **캐싱 효율**: 번들에 포함되면 JS가 바뀔 때마다 다시 다운로드되지만, 외부 폰트 파일은 변경되지 않으면 브라우저가 캐시를 재사용할 수 있어요.
